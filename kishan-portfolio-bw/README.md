# Kishan Maddheshiya | Portfolio

Black and white portfolio website built with plain HTML, CSS and JavaScript. No install or build step needed.

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Edit
- `index.html`: content and structure
- `style.css`: colours and design (see `:root` at the top)
- `script.js`: project popup text, menu and form
- `images/`: put your photos here and update the `src` paths
- `resume.pdf`: used by the Download resume button

## Put it on GitHub
```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```

## Make it live with GitHub Pages
Repository > Settings > Pages > Source: **Deploy from a branch** > Branch: **main** / **(root)** > Save.
The site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO/` after a minute or two.
